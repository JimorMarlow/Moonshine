# Moonshine Web UI — История изменений

## О проекте

### Moonshine Distillation Monitoring

Веб-интерфейс мониторинга процесса дистилляции для проекта Moonshine (Arduino).

**Особенности:**
- SVG-схема дистилляционной установки с анимациями
- Отображение датчиков температуры и потока в реальном времени
- Анимация пузырьков в нагревателе (зависит от температуры)
- Анимация капель продукта (зависит от температуры пара)
- Вращающиеся турбины в датчиках потока
- Градиентные трубы для выходной воды (цвет зависит от температуры)
- Система правил с предупреждениями и ошибками
- Симуляция работы для демонстрации

**Последняя версия:** `qwen-distillation.043.html` (встроен в src/web-ui.cpp, v1.2.10)

---

### WiFi Setup UI

Веб-интерфейс для первичной настройки WiFi подключения устройств на базе ESP8266/ESP32.

**Особенности:**
- Сканирование доступных WiFi сетей
- Подключение к выбранной сети с сохранением настроек
- Настройка точки доступа (SSID, пароль)
- Сброс к заводским настройкам
- iOS-стиль дизайна
- Локализация EN/RU
- Контейнер информации об устройстве с иконкой

**Последняя версия:** `qwen-wifi_setup.008.html` (v1.0.8)

---
