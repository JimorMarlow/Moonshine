# Moonshine Web UI — История изменений

## О проекте

Веб-интерфейс мониторинга процесса дистилляции для проекта Moonshine (Arduino).

**Особенности:**
- SVG-схема дистилляционной установки с анимациями
- Отображение датчиков температуры и потока в реальном времени
- Анимация пузырьков в нагревателе (зависит от температуры)
- Анимация капель продукта (зависит от температуры пара)
- Вращающиеся турбины в датчиках потока
- Градиентные трубы для выходной воды (цвет зависит от температуры)
- Система правил с предупреждениями и ошибками
- Симуляция работы для демонстрации

**Последняя версия:** `qwen-distillation.031.html` (v1.0.25)

### v029
**Изменения:**
- Изменён путь трубы Cool.Flow: сначала влево до середины конденсатора (x=420), потом вверх
- Было: `M 470 190 L 435 190 L 435 165 L 420 165`
- Стало: `M 470 190 L 420 190 L 420 165`
- Добавлены градиенты для вертикальных частей выходных труб
- Версия обновлена: v1.0.22 → v1.0.23

### v030
**Изменения:**
- Разделение выходных труб на вертикальные и горизонтальные части
- Вертикальные части: `dfWaterOutPipeV`, `coolWaterOutPipeV`
- Горизонтальные части: `dfWaterOutPipeH`, `coolWaterOutPipeH`
- Градиенты применяются только к вертикальным частям
- **Проблема:** трубы сместились вверх, градиенты не отображались
- Версия обновлена: v1.0.23 → v1.0.24

### v031
**Изменения:**
- Возвращены оригинальные пути труб (как в v028)
- Градиенты применены через атрибут `stroke="url(#gradient)"` непосредственно в SVG
- Градиент вертикальный: снизу (20°C, синий) → сверху (текущая температура)
- **Проблема:** градиент применён к неправильным трубам (выходные вместо входных)
- Версия обновлена: v1.0.24 → v1.0.25

### v032
**Изменения:**
- Градиенты перемещены на **входные трубы** от датчиков потока
- Входные трубы разделены на горизонтальные и вертикальные части:
  - `dfWaterInPipeH` / `coolWaterInPipeH` — горизонтальная часть (без градиента)
  - `dfWaterInPipeV` / `coolWaterInPipeV` — вертикальная часть (с градиентом)
- Выходные трубы к датчикам температуры — сплошной цвет (без градиента)
- Градиент: 20°C (синий) → текущая температура DF.T/Cool.T
- Версия обновлена: v1.0.25 → v1.0.26

## Как продолжать работу

1. Открыть последнюю версию файла (например, `qwen-distillation.031.html`)
2. Внести необходимые изменения
3. Сохранить в новый файл с увеличенным номером (например, `qwen-distillation.032.html`)
4. Обновить версию в заголовке `Moonshine vX.X.X`
5. Добавить запись в этот файл

## Технические детали

### Датчики
| Сенсор | Описание | Диапазон |
|--------|----------|----------|
| Heater | Температура в баке | 20-95°C |
| Steam | Температура пара | 20-95°C |
| DFT | Дефлегматор (выход) | 15-40°C |
| CoolT | Конденсер (выход) | 15-35°C |
| DFFlow | Поток дефлегматор | 0-400 ml/min |
| CoolFlow | Поток конденсер | 0-400 ml/min |

### Анимации
- **Пузырьки:** 7 уровней скорости (60-90+°C)
- **Капли:** 3 уровня (1Hz, 2Hz, 4Hz при 65-70-75+°C)
- **Турбины:** 3 уровня скорости потока

### Градиенты
- **columnGradient:** Колонна ( Heater → Steam )
- **vaporGradient:** Паропровод ( Steam → CoolT )
- **dfOutVertGradient:** Выходная труба DF ( 20°C → DFT )
- **coolOutVertGradient:** Выходная труба Cool ( 20°C → CoolT )
